# SKAVEN

**SKAVEN — Web Intelligence and Security Reconnaissance**

Created by **Anonymous-beta (Chinedu)**.

SKAVEN is an Android reconnaissance application built with Flutter.

## Features

- HTTP and HTTPS target inspection
- Bounded same-origin website crawling
- Public JavaScript and CSS asset discovery
- Observable API route extraction
- DNS resolution
- HTTPS certificate inspection
- HTTP response-header analysis
- Passive WAF fingerprinting
- Technology and framework fingerprinting
- Scan findings and history
- Copyable reconnaissance reports
